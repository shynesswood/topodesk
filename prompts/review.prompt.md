# 代码审查 Prompt 模板

## 使用方式

将此模板配合变更范围发给 AI，要求 AI 执行架构审查和代码审查。

## 前置知识加载

开始审查前，请先确保已阅读：

- `.ai/project.md`
- `.ai/architecture.md`
- `.ai/coding-rules.md`
- `.ai/module-boundary.md`

并根据修改范围选择性阅读相关模块知识文件。

## 审查清单

### 架构层面

- [ ] 新增代码是否遵循既有分层（组件 → store → service → Wails → Go service）。
- [ ] 是否避免了跨越模块边界的直接调用。
- [ ] 新增状态是否正确选择了对应的 Zustand store。
- [ ] 新增文件是否在正确的目录中。

### 数据完整性和安全

- [ ] 项目 JSON 字段变更是否同步了 Go 模型、TypeScript 类型和 Wails 转换逻辑。
- [ ] 保存加载链路是否完整保留所有新增字段。
- [ ] 是否扩大了凭证泄露风险。
- [ ] 命令执行是否有确认、超时和错误处理。

### 代码质量

- [ ] 是否有明显的代码重复或过度抽象。
- [ ] 错误路径是否被正确处理。
- [ ] 是否有 console.log 或敏感信息泄露。
- [ ] TypeScript 类型是否安全。

### 模块边界

- [ ] 新增代码是否遵循各模块"禁止事项"清单。
- [ ] 是否给模块引入了不应有的依赖。
